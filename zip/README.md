# Packed builds (1.2.2)

Unzip the file for your browser, then load that folder.

| File | Browser |
| --- | --- |
| `spinwheelplus-chrome.zip` | Chrome |
| `spinwheelplus-edge.zip` | Edge |
| `spinwheelplus-firefox.zip` | Firefox |

Chrome: `chrome://extensions` -> Developer mode -> Load unpacked.

Edge: `edge://extensions` -> Developer mode -> Load unpacked.

Firefox: `about:debugging` -> This Firefox -> Load Temporary Add-on -> `manifest.json` inside the unzipped folder.
